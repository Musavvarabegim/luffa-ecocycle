# Luffa EcoCycle

**Luffa EcoCycle** — Jizzax sharoitida luffa o‘simligidan tabiiy mahsulotlar ishlab chiqarish g‘oyasi uchun yaratilgan o‘zbek tilidagi statik veb-sayt, biznes-reja konsepsiyasi va interaktiv moliyaviy kalkulyator.

## Fayllar

- `index.html` — sahifa tuzilishi va o‘zbekcha loyiha mazmuni
- `styles.css` — responsiv dizayn
- `app.js` — interaktiv moliyaviy hisob-kitob
- `.nojekyll` — GitHub Pages uchun yordamchi fayl

## Saytni kompyuterda ko‘rish

1. ZIP faylni oching.
2. `index.html` faylini brauzerda oching.
3. Kalkulyatordagi qiymatlarni o‘zgartirib, hisob-kitobni tekshiring.

Internet bo‘lsa, tashqi shrift va suratlar yuklanadi. Ular yuklanmasa ham sahifaning asosiy matni va kalkulyatori ishlaydi.

## GitHub’ga yuklash

1. https://github.com/new sahifasiga kiring.
2. Repository nomini `luffa-ecocycle` deb kiriting.
3. Public tanlang (agar loyihani ochiq namoyish qilmoqchi bo‘lsangiz) va **Create repository** tugmasini bosing.
4. Ushbu ZIP’ni oching. Ichidagi fayllarni repository’ning asosiy (root) papkasiga yuklang — `index.html` aynan shu papkada bo‘lishi kerak.
5. GitHub repository’da **Add file → Upload files** ni bosing, fayllarni sudrab olib kiriting va **Commit changes** qiling.
6. Repository ichida **Settings → Pages** bo‘limini oching.
7. **Build and deployment** ostida **Deploy from a branch** ni tanlang.
8. Branch sifatida `main`, papka sifatida `/(root)` ni tanlab **Save** bosing.
9. Bir necha daqiqadan keyin Pages bo‘limida chiqarilgan saytingiz URL manzili paydo bo‘ladi. Odatda u `https://GITHUB-USERNAME.github.io/luffa-ecocycle/` ko‘rinishida bo‘ladi.

## Moliyaviy kalkulyator

Kalkulyator quyidagilarni foydalanuvchi kiritgan qiymatlar asosida hisoblaydi:

- sotiladigan dona soni va sotuv ulushi;
- tushum;
- o‘zgaruvchan va doimiy xarajatlar;
- soddalashtirilgan operatsion natija;
- zararsizlik nuqtasi;
- oddiy sarmoya qoplanish muddati.

Boshlang‘ich qiymatlar **faqat namuna**. Ular tasdiqlangan bozor narxlari, real tannarx yoki foyda kafolati emas. Grant arizasiga kiritishdan oldin uskuna takliflari, urug‘ va xomashyo narxlari, mehnat, qadoq, logistika, soliqlar va xaridorlardan olingan dalillar bilan yangilang.
